# 📈 Bond Portfolio Dashboard

PET-проект: интерактивный дашборд для анализа портфеля облигаций с расчётом доходности, рисков и купонного денежного потока.

## Возможности

- Загрузка справочника облигаций и исторических цен с MOEX (по одному ISIN, списком или из CSV).
- Ручной ввод сделок (покупка/продажа) с автоматическим расчётом текущего портфеля.
- Расчёт доходности к погашению (YTM) с учётом НКД, модифицированной дюрации и выпуклости.
- Портфельные метрики: средневзвешенная YTM, дюрация, текущая стоимость, VaR (исторический метод).
- Купонный календарь: таблица будущих выплат и график денежного потока по месяцам.
- Экспорт истории цен в CSV.
- Управление данными: удаление отдельных облигаций, очистка портфеля, полный сброс базы.
- Веб-интерфейс на Streamlit с кэшированием для высокой производительности.

## Технологии

- **Python 3.12**
- **Streamlit** — веб-интерфейс
- **Pandas, NumPy** — обработка данных
- **Plotly** — графики
- **SQLite** — локальная база данных
- **MOEX ISS API** — источник рыночных данных
- **SciPy** — численные расчёты (YTM, дюрация)
